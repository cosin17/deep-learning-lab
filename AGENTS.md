# Version submission

Before creating a Git commit or pushing a modified version, summarize the changes and validation results, then ask the user whether to submit this version.

Prepare and test the changes before asking. Proceed with the commit or push only after the user explicitly authorizes that version. Authorization for one version does not authorize later versions.

An explicit user request to publish or push the current version counts as authorization for that version.

用户偏好：后续修改完成后，先询问是否提交本次版本；获得本次授权后，才能创建 Git 提交或推送。
